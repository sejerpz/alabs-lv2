# BlipMachine (aLabs) — LV2 prototype

A 5-voice synthesized percussion module for the MOD Dwarf: kick, snare, closed hat, open hat and
zap, each purely synthesized (no samples), triggered by MIDI note number. Companion to
[Euclides](../euclides/) — same voices, same default GM-ish note numbers (kick 36, snare 38, CH
42, OH 46, zap 37) — but it listens on any MIDI input, so it works with any sequencer, host or
keyboard.

Built with [DPF](https://github.com/DISTRHO/DPF) instead of raw LV2, unlike the other plugins in
this collection — see [Build](#build) for what that changes.

## Parameters

Global: `Master` (dB).

Port order: **Global**, then the **Voice** block with every voice's `Mute`, `Note` (which incoming
MIDI note triggers it), `Level`, `Tune`, `Decay`, `Tone`, `Mod` and `Pan`.

`Level` sets the voice's own gain; the actual trigger amplitude is `Level × velocity/127`.
`Mute` cuts a voice's audio trigger, with a 5 ms ramp on the tail.

| Voice  | Note | Tune                 | Tone                  | Mod                     |
|--------|------|----------------------|-----------------------|--------------------------|
| Kick   | 36   | final frequency (Hz) | lowpass cutoff        | sweep (semitones)        |
| Snare  | 38   | body frequency (Hz)  | noise bandpass center | snappy (body ↔ noise)    |
| CH     | 42   | bank semitones       | highpass              | noise (metal ↔ noise)    |
| OH     | 46   | (follows CH)         | highpass              | noise                    |
| Zap    | 37   | final frequency (Hz) | pulse width           | sweep (octaves)          |

The metallic bank (6 square waves, 808-style) is shared between CH and OH and tuned by CH's
`Tune`; OH's `Tune` has no effect yet. CH chokes OH.

## Source layout

```
Makefile                      top-level build (+ make moddwarf, make render)
plugins/BlipMachine/
  DistrhoPluginInfo.h          DPF metadata (URI urn:andrea:blipmachine)
  Params.hpp                   parameter table (symbols, ranges, defaults)
  Dsp.hpp                      PolyBLEP pulse, TPT SVF, envelopes, voices
  Engine.hpp                   MIDI-note dispatch, mixer — independent of DPF
  BlipMachinePlugin.cpp        thin DPF wrapper (sample-accurate MIDI split)
lv2-ttl/                       pre-generated TTL, used by cross builds
test/render.cpp                offline WAV render of one note, no host needed
test/lv2host_test.cpp          minimal LV2 host for manual testing
bin/blipmachine.lv2/           the assembled bundle (generated by make)
```

No modgui yet: the MOD UI shows the generic control panel.

## Build

```sh
git clone --recursive https://github.com/DISTRHO/DPF.git dpf
make            # native build, generates the TTL and copies it into lv2-ttl/
make render     # offline render tool -> build/render
```

### Build for the Dwarf

**Without the MOD toolchain** (recommended for experimenting):

```sh
pip install ziglang
./build-moddwarf.sh          # -> dist/blipmachine-moddwarf.tar.gz
```

Zig links against glibc 2.17 and statically includes libc++, so the `.so` only depends on the
Dwarf's libc/libm/libpthread/libdl. The `-z nodelete` flag avoids a crash on process exit after
`dlclose` (the bundled libc++'s static destructors).

**With mod-plugin-builder** (`./bootstrap.sh moddwarf`, workdir `~/mod-workdir`):
`make clean && make moddwarf`.

A generic cross-compiler (e.g. Ubuntu 24.04's `aarch64-linux-gnu-g++`) compiles fine but needs
GLIBC 2.38, too recent for the Dwarf.

In a cross build the TTL generator cannot run, so the files committed in `lv2-ttl/` are copied
instead. **If you change the parameters, run a native `make` first** to regenerate them.

### Install / publish

```sh
make install                                      # into ~/.lv2 (native build)
./build-moddwarf.sh && make publish [DWARF=192.168.52.1]   # hot install on the Dwarf
```

`publish` hot-installs the bundle through mod-ui (the plugin must not be in the current
pedalboard); it checks the binary is an aarch64 build before sending it, same as the other
plugins in this collection.

## Offline tools (test/)

- `test/render.cpp`: triggers one MIDI note and renders straight to WAV, no LV2 host needed.
- `test/lv2host_test.cpp`: a minimal LV2 host (one note-on, raw audio dump), also useful to run
  the aarch64 build under `qemu-aarch64 -L /usr/aarch64-linux-gnu` on a PC.

```sh
g++ -Idpf/distrho/src/lv2 -Iplugins/BlipMachine test/lv2host_test.cpp -o build/lv2host -ldl
./build/lv2host bin/blipmachine.lv2/blipmachine_dsp.so 375 36 114   # note 36, velocity 114

./build/render out.wav [dur_ms] [note] [vel] [symbol=value ...]
./build/render kick.wav 300 36 114 kick_tune=44 kick_decay=180 kick_tone=180
```

## Known limits

- Zap: a placeholder model (pulse with an exponential sweep), to be redone after analyzing the
  real sample.
- No parameter smoothing: changing Level/Pan during the tail can zipper.
- Parameters are read per block (DPF), not per sample.
- One-shot voices: note-off has no effect, only note-on (velocity) matters.
- No modgui yet.
